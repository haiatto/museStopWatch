# サンプルアプリ

Museストップウォッチ用のミニアプリとアバターのサンプルです。Muse はここのソースを見本にしたり、
そのまま組み立てて入れたりします（`app.doc` の手順）。

- **ソースだけを置きます。** 組み立てたもの（`.mswapp`、`build/`）は置きません。
  使うときは `python3 sdk/build.py apps/<名前>` で自分で組み立てます。
- **外のソースや素材を使わずに作ったものだけを置きます。** ほかのプログラムの移植や、
  権利が自分にない絵・音・データを使うものは置きません。
- ライセンスはリポジトリと同じ MIT（[LICENSE](../LICENSE)）です。

| フォルダ | 名前 | 中身 |
|---|---|---|
| [blocks](blocks/) | おちものブロック | 落ちものパズル |
| [pyoko](pyoko/) | ぴょこの森 | 横スクロールのアクション |
| [aquarium](aquarium/) | まるい水槽 | 魚が泳ぐ水槽 |
| [mimi](mimi/) | みみ | マイクの音の大きさと、録音・再生 |
| [sensors](sensors/) | センサー | 時刻・電池・歩数・PORT.A の一覧 |
| [catmine](catmine/) | ねこマインスイーパー | 猫が隠れているマインスイーパー。鳴き声はコードで作る |
| [kamisumo](kamisumo/) | かみずもう | PORT.A の Dual Button で遊ぶ紙相撲。かけ声の音（`data/`）は入れていない |
| [piano](piano/) | かんたん鍵盤 | タッチで鳴る 8 つの鍵盤 |
| [shizuku](shizuku/) | しずく | アバター |

## 1 つのアプリのフォルダ

- `app.json`: id、名前、版、アイコン（PORT.A を使うアプリは `port` も）
- `*.c`: ソース
